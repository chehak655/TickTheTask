# TaskFlow Web Frontend

Modern responsive task management interface built with React, Vite, and Tailwind CSS.

## Features
- Fast HMR with Vite
- Tailwind CSS styling
- Modular component hierarchy (`components/`, `pages/`, `services/`, `context/`, `hooks/`, `utils/`)
- Axios client configured for backend integration

## Setup & Running

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   ```bash
   copy .env.example .env
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   The application will be accessible at `http://localhost:5173`.

4. **Production Build**:
   ```bash
   npm run build
   ```
